# Structural Review: M3 wave A.1

- **Status:** open
- **Findings:** 2 (1 duplicates)
- **Reviewed:** `autoloop/m3-wave-a.1` at `a75597b9`, 2026-11-26

**Scope.** `git diff --stat main...autoloop/m3-wave-a.1` touches two packages, and no interpreter code. In `pkg/engine/cards` the wave added `register` and `deploysOrAttacks` to `cards.go`, a new `cards_test.go`, and changed every definition file's `init` and the three Colossi. I read the whole package. In `pkg/engine` the wave changed only test files: it added `cardWithTrigger` and `deployPaid` (`scenario_test.go`), moved `wantOptions` (`targeting_test.go`) and `activateChoosing` (`cards_path_maneuvers_test.go`), and rewrote 15 card test files to call them. I read those helpers, the files that call them, and every other test helper that gives a card and deploys it, or copies a definition (`trigger_test.go`, `heal_armor_test.go`, `foundation_test.go`, `cards_path_test.go`, `cards_animus_test.go`, `cards_animus_apostle_test.go`, `cards_concordia_outrigger_test.go`, `cards_soulless_eye_test.go`). `pkg/engine`'s non-test files are as structural review 16 left them, and I did not survey them again.

Placement and imports hold: `cards` imports only `ability` (`go list -deps ./pkg/engine/cards`). No old name survives the four moves: `git grep` for the sixteen helpers #190 and #193 removed finds them only in task and directive text, and `Defs[name] = def` appears only in `register`. Sharing the `Effect` slices between `deploysOrAttacks`'s two triggers is safe: the only engine code that appends to an `Effect`'s slices, `joinModes` ([placement.go:328-335](../../../../pkg/engine/placement.go)), starts from a nil `Effect`. No unapplied directive on the run branch's `BOARD.md` covers either finding below.

A throwaway probe test in `cards` (not committed) compared every pair of triggers in each `Defs` entry with `Hook` cleared. Four cards have a pair that differs only in `Hook`: the three Colossi, which now go through `deploysOrAttacks`, and *Fungal Evangelist* (finding 1). No two activated abilities on one card are equal. In `data/cards`, the only other text with a two-hook ability ("deploys or …", "… or is killed", "… or attacks") is *Stardust Colossus*, which #191 already gives `deploysOrAttacks`.
