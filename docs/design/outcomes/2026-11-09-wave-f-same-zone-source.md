### ❓ Open Ruling Question: what "in the same zone" reads once the source has moved or left (2026-11-09)

- **Question:** "Chosen asset in the same zone" is a zone criterion relative to the ability's source (`FR-TGT-001` Zone). The target is chosen when the trigger is placed, while the source is on the battlefield, and checked again just before it resolves (`FR-TGT-003`).
  1. **The source moved.** If the source is in the other battlefield zone by the second check, is "the same zone" the source's zone at that moment, so that a target still in the old zone is illegal? Or the zone the source was in when the target was chosen?
  2. **The source left the battlefield.** If the source has left the battlefield by the second check (or, in principle, by placement), which holds?
     - (a) "The same zone" is the source's last-known zone, from immediately before it left (`FR-ZON-004`), so a target still in that zone stays legal and gains the armor.
     - (b) Nothing is in the same zone as a source that isn't on the battlefield, so the target is illegal and the ability does nothing.
- **Source:** task T-0205 (wave F run, `autoloop/m2-wave-f`, session 4), which builds the same-zone filter criterion for *Broken Horn Armorer*. T-0205's plan left the departed-source reading "settled when this task is written, against FRD 01 then". FRD 01 doesn't settle it.
- **Cards affected** (`data/cards/units-and-structures-path.csv:8`): *Broken Horn Armorer* (Path Unit, M2, wave F, Path **starter deck**, 2 copies): *"Whenever this unit moves to a new zone, chosen asset in the same zone gains 1 armor."* The same criterion is reused by cards deferred under board directive #14 (b) or outside M2: the same-zone auras (*Animoceps Stalk*, *Animoceps Node*, *Melodic Pummeler*, *Hulking Incongruity*, *Ancestral Monument*), whose source is always on the battlefield while the aura applies, *Hammerhand Bivouac* (untargeted, `SVY-R3`), and the activated "chosen … in the same zone" abilities of *Tempest Runner*, *Mobile Armory* and *Land Fortress*.
- **Current FRD 01 & engine state** (FRD 01 v3.22; `pkg/engine` on `autoloop/m2-wave-f` at `97214a0`):
  - `FR-TGT-003` (line 389) makes a target illegal if it "moved to a battlefield zone that no longer satisfies the ability's zone restriction" or "no longer satisfies dynamic stat/filter criteria". It speaks of the target moving, not the source.
  - `FR-ZON-004`'s *Values Read From the Source* (line 242, `SVY-R10`) reads a departed source's last-known values, but names its stats ("deal damage equal to its power"), not its zone. `FR-CBT-002` Step 3 (line 570) uses an attacker's last-known controller, for attacks only.
  - Read as settled, and not asked: "chosen asset" with no "other" may choose the Armorer itself (`FR-TGT-001` conjunction), and the Main Theater is shared while Reserves are each player's own (`FR-ZON-001`, lines 218–219), so in the Main Theater an opposing asset can be chosen and in Reserves only the controller's own.
  - Engine: `matchesFilter` (`pkg/engine/filter.go:85`) takes the source's asset ID and is used at both checks: placement (`pkg/engine/targeting.go:93`) and resolution (`pkg/engine/effects.go:41`). `itemSource` (`pkg/engine/effects.go:364`) already returns a departed source's last-known record (`pkg/engine/state.go:168`). There is no same-zone criterion on `ability.Filter` yet (`pkg/engine/ability/ability.go:217`).
  - Reach in M2: actions need an empty Resolution Stack (`FR-TRN-001`, line 292), so nothing responds to the trigger. Only an item above it on the stack, or the rest of the effect that moved the Armorer, could move it again or remove it. No M2 card I found does either, so both cases are reachable in principle only. The engine still has to do one or the other.
- **Lead's recommendation:** 1: the source's zone at the second check. A same-zone criterion is a dynamic filter criterion, which `FR-TGT-003` re-checks against the state at resolution. 2 (a): the last-known zone. It is the effect's own source, whose last-known values `SVY-R10` already reads, and the armor then goes where the player chose it, as it does for the departed source's damage in `SVY-R10`'s *Necropolis Hunt* example.
